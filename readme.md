# School System Management - Flask Web Application

This project is a Flask-based web application designed to manage a school system. It includes functionalities for user registration, login, and managing students.

### File Descriptions

#### 1. `app.py`
The main application file that initializes the Flask app and sets up the API endpoints. Key functionalities include:
- Configuration for the database and session management.
- Initialization of CORS, database, and migration.
- Definition of API resources for user registration, login, logout, and student management.
- Error handling for bad requests.

#### 2. `extention.py`
Contains the initialization of the Bcrypt extension used for password hashing. It creates an instance of Bcrypt that can be imported and used throughout the application.

#### 3. `models.py`
Defines the database models using SQLAlchemy:
- **Student**: Represents a student with validation for the name length.
- **User**: Represents a user with methods for password hashing and checking.

This file initializes the database and migration objects but does not create a Flask app instance.

#### 4. `seed.py`
A script used to populate the database with initial data. It:
- Creates 10 student records using the Faker library to generate random names.
- Runs within the application context to access the database.

#### 5. `decorator.py`
Defines a custom decorator `login_required` that checks if a user is logged in (i.e., if a user ID exists in the session). This decorator is used to protect certain API endpoints from unauthorized access.

#### 6. `requirements.txt`
Lists all dependencies required for the project, including specific versions of libraries such as:
- Flask
- Flask-RESTful
- Flask-SQLAlchemy, and others.

Use this file to set up your Python environment.

#### 7. `.gitignore`
Specifies files and directories to be ignored by Git, including:
- Virtual environments
- Cache files
- Compiled Python files

#### 8. `migrations/`
Contains migration scripts generated by Alembic to manage database schema changes:
- **README**: A brief description of the migration setup.
- **versions/**: Contains individual migration scripts:
  - `66cc7ebc909c_recreating_initial_migration.py`: Creates the initial student table.
  - `03e977306a9e_added_user_model.py`: Adds the user table to the database.

#### 9. `guide.txt`
Outlines the functionalities of the school system, including API endpoints for viewing students and teachers. It also provides a domain model for the application.

#### 10. `QDD.txt`
Contains a list of questions and answers related to web development concepts such as:
- Sessions
- Cookies
- JWT (JSON Web Tokens)
- Password encryption
- Access control

#### 11. `readme.md`
This file provides an overview of the project, its purpose, and setup instructions (currently empty in this context).
